## Landing Page de Boas Vindas

A página é um projeto público da Youtuber Rafaella Ballerini que faz parte de uma série de videoaulas para iniciantes em JavaScript. A landing page consiste em uma interface com um texto de boas-vindas, uma breve descrição, seguida de um input e um botão para personalização do nome do visitante.

### Tecnologias utilizadas
- HTML + JavaScript através de inline event handler (método utilizado)
- CSS

## Mini Slideshow

O slideshow é uma adaptação de um projeto público do youtuber Gustavo Campelo. Nele, o produtor de conteúdo ensina a construir uma apresentação funcional com três slides usando HTML e CSS, mas principalmente demonstrando a lógica e as ferramentas básicas de JavaScript por trás da navegação entre os slides.

### Tecnologias utilizadas
- HTML
- CSS
- JavaScript
