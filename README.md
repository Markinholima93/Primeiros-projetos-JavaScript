# Mini Slideshow

Projeto com o objetivo de mostrar meu progresso de aprendizagem em JavaScript.

O slideshow é uma adaptação direta de um projeto público do youtuber Gustavo Campelo. Nele, o produtor de conteúdo ensina a construir uma apresentação funcional com três slides usando HTML e CSS, mas principalmente demonstrando a lógica e as ferramentas básicas de JavaScript por trás da navegação entre os slides.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript
